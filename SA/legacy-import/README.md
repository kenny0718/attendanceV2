# 舊文件匯入區

此目錄保存從原本 `/opt/attendance-system/docs` 匯入的歷史文件。

## 原則

- 此區內容 **不再是正式權威文件**
- 僅供追溯歷史決策、修復紀錄、工作票脈絡
- 若其中資訊仍有效，必須被重新整理並回寫到：
  - `SA/architecture/`
  - `SA/modules/`
  - `SA/governance/`

## 來源

- 原始目錄：`/opt/attendance-system/docs`
- 匯入方式：整體保留，避免決策資訊遺失

## 後續處理

1. 新開發一律只更新 `SA/`
2. 若需引用舊資訊，先比對程式現況後再回寫到正式文件
3. 不可再把新文件寫回舊 `docs/`
