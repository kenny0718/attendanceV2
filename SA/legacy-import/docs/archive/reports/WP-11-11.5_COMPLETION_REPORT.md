#### C. 刪除 getGPSLocation() 方法
- **位置**: 原第 243-283 行（約 40 行）
- **動作**: 完全移除
- **原因**: 功能已移至 locationAdapter

#### D. 重構 outCheckpointSubmit() 方法
**修改前**:
```javascript
const deviceType = this.detectDeviceType()

const payload = {
  device_type: deviceType,
  notes: reasonText.trim()
}

if (deviceType === 'mobile') {
  const gpsData = await this.getGPSLocation()
  payload.gps = gpsData
}
```

**修改後**:
```javascript
const deviceType = detectDeviceType()

const payload = {
  device_type: deviceType,
  notes: reasonText.trim()
}

// 使用 adapter 獲取定位（如果需要）
const gpsData = await getLocationIfRequired()
if (gpsData) {
  payload.gps = gpsData
}
```

**改進**:
- 使用 adapter 的 `detectDeviceType()` 函式
- 使用 `getLocationIfRequired()` 自動判斷是否需要 GPS
- 程式碼更簡潔，邏輯更清晰

#### E. 更新 handleError() 方法
**修改前**:
```javascript
handleError(error) {
  let errorMessage = '操作失敗'
  let errorCode = null
  
  if (error.status) {
    // ...
  }
}
```

**修改後**:
```javascript
handleError(error) {
  // Handle LocationError first
  if (error instanceof LocationError) {
    return {
      message: error.message,
      code: error.code,
      originalError: error.originalError
    }
  }
  
  let errorMessage = '操作失敗'
  let errorCode = null
  
  if (error.status) {
    // ...
  }
}
```

**改進**:
- LocationError 優先處理
- 統一錯誤格式
- 保留原始錯誤物件
