## ❌ 常見問題

### Q1: GPS 定位一直失敗怎麼辦？

```
A: 檢查以下項目
1. 是否在室外？
2. GPS 是否已開啟？
3. 瀏覽器權限是否允許？
4. 是否有網路連線？
5. 等待時間是否足夠？（最多 10 秒）
```

### Q2: PC 也要求 GPS 怎麼辦？

```
A: 這是 Bug！
- 記錄為 Blocker Bug
- PC 不應該要求 GPS
- 需要修復後重新測試
```

### Q3: 錯誤訊息不正確怎麼辦？

```
A: 記錄實際訊息
- 在報告中記錄預期 vs 實際
- 如果訊息誤導使用者，標記為 Critical Bug
- 如果只是文字不同，標記為 Minor Bug
```

### Q4: 測試環境無法部署怎麼辦？

```
A: 暫停 QA
- 通知開發團隊
- 等待環境修復
- 更新 QA 狀態為「待執行」
```

## 🎯 QA 完成後

### 如果全部通過

1. **建立 QA Tag**
   ```bash
   cd /opt/attendance-system
   git tag -a milestone/wp-11-11.5-qa-passed -m "WP-11-11.5: Manual QA Passed"
   git push origin milestone/wp-11-11.5-qa-passed
   ```

2. **通知團隊**
   - QA 已通過
   - 可以開始 WP-11-12
   - 附上 QA 報告

3. **更新文件**
   - GATE_PROGRESS_TRACKER.md
   - NEXT_WP_TICKET.md

### 如果發現 Blocker Bug

1. **通知開發團隊**
   - 提供 Bug 報告
   - 提供重現步驟
   - 提供測試環境資訊

2. **等待修復**
   - 開發團隊修復
   - 提交修復 commit
   - 通知 QA 重新測試

3. **重新執行 QA**
   - 驗證 Bug 已修復
   - 執行完整回歸測試
   - 更新 QA 報告
