   - **影響**：即使 API 正常，前端也無法顯示外出/返回資訊

## 🛠️ 修復內容

### 1. 後端 API 實作

**檔案**: `backend/app/modules/attendance/api.py`

**新增端點**:

#### POST /v1/attendance/break-out
```python
@router_v1.post("/break-out", response_model=BreakOutResponse, status_code=201)
async def break_out(...)
```
- 功能：外出打卡
- 允許連續外出（不需要先返回）
- 記錄 GPS 座標（如有）
- 記錄外出原因（notes）
- 返回：punch_id, session_id, punch_time

#### POST /v1/attendance/break-in
```python
@router_v1.post("/break-in", response_model=BreakInResponse, status_code=201)
async def break_in(...)
```
- 功能：返回打卡
- 記錄 GPS 座標（如有）
- 記錄備註（notes）
- 返回：punch_id, session_id, punch_time

#### GET /v1/attendance/break-punches
```python
@router_v1.get("/break-punches")
async def get_break_punches(...)
```
- 功能：獲取今日外出/返回記錄
- 返回：punch_id, punch_type, punch_time, notes, location
- 按時間倒序排列
- 限制：今日記錄

**修改內容**:
- 添加 BreakOutRequest, BreakInRequest, BreakOutResponse, BreakInResponse 到 imports
- 使用現有的 `AttendanceSessionRepository.create_punch()` 方法
- 保持 company_id 和 user_id 的 tenant isolation
- 使用現有的 JWT/tenant context

### 2. 前端邏輯修復

**檔案**: `frontend/src/stores/attendance.js`

#### 修復 fetchTodayStatus()

**問題**:
```javascript
// ❌ 舊版：使用舊值，不更新
this.todayStatus = {
  break_out: this.todayStatus.break_out,
  break_in: this.todayStatus.break_in,
}
```

**修復**:
```javascript
// ✅ 新版：從 break-punches API 獲取最新資料
const breakData = await attendanceApi.getBreakPunches({ limit: 50 })
const breakStarts = breakData.punches.filter(p => p.punch_type === 'break_start')
const breakEnds = breakData.punches.filter(p => p.punch_type === 'break_end')

if (breakStarts.length > 0) breakOut = breakStarts[0].punch_time
if (breakEnds.length > 0) breakIn = breakEnds[0].punch_time

this.todayStatus = {
  break_out: breakOut,
  break_in: breakIn,
}
```

#### 修復 fetchRecentLogs()

**問題**:
```javascript
// ❌ 舊版：只顯示上班/下班記錄（不包含外出/返回）
this.recentLogs = data.sessions.map(session => ({
  attendance_type: isPunchOut ? 'OUT' : 'IN',
}))
```

**修復**:
```javascript
// ✅ 新版：合併 session logs 和 break logs
const sessionLogs = data.sessions.map(...)
const breakData = await attendanceApi.getBreakPunches({ limit: 20 })
const breakLogs = breakData.punches.map(punch => ({
  attendance_type: punch.punch_type === 'break_start' ? 'BREAK_OUT' : 'BREAK_IN',
  notes: punch.notes
}))

// 合併並按時間排序
this.recentLogs = [...sessionLogs, ...breakLogs]
  .sort((a, b) => new Date(b.timestamp) - new Date(a.timestamp))
  .slice(0, 10)
```
