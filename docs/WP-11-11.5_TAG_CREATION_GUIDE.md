## ❌ 常見錯誤

### 錯誤 1: QA 未完成就建立 tag

```bash
# ❌ 錯誤：QA 還沒跑完就建立 tag
git tag -a qa-passed/wp-11-11.5 -m "QA Passed"

# ✅ 正確：等 QA 完成並確認通過後再建立
```

### 錯誤 2: Tag 訊息不完整

```bash
# ❌ 錯誤：訊息太簡略
git tag -a qa-passed/wp-11-11.5 -m "QA passed"

# ✅ 正確：包含完整資訊
git tag -a qa-passed/wp-11-11.5 -m "WP-11-11.5: QA Passed

測試日期: 2026-03-08
QA 負責人: John Doe
測試結果: 4/4 通過
結論: 可作為穩定基線"
```

### 錯誤 3: 忘記推送 tag

```bash
# ❌ 錯誤：只在本地建立 tag
git tag -a qa-passed/wp-11-11.5 -m "QA Passed"

# ✅ 正確：建立後推送到遠端
git tag -a qa-passed/wp-11-11.5 -m "QA Passed"
git push origin qa-passed/wp-11-11.5
```

## 🔄 如果需要修改 tag

### 刪除錯誤的 tag

```bash
# 刪除本地 tag
git tag -d qa-passed/wp-11-11.5

# 刪除遠端 tag
git push origin :refs/tags/qa-passed/wp-11-11.5
```

### 重新建立正確的 tag

```bash
# 重新建立 tag
git tag -a qa-passed/wp-11-11.5 -m "正確的訊息"

# 推送到遠端
git push origin qa-passed/wp-11-11.5
```
